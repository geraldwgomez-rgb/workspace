# Pitch de 90 segundos (versión natural): Gerald Williams



## 1. Pitch en inglés (170 palabras)

Hi! I'm **Gerald Williams**, and I love building things for the web.

I'm a web developer from **Medellín, Colombia**. I work with **JavaScript, React, Node.js, and Supabase**. I use JavaScript to make things work, React to build the screens people see and click, Node.js for the server behind them, and Supabase for the database where the data is stored.

My main project is **SMC**. It's an accounting system that I built myself. Accounting can be confusing, so I wanted to make it simple and clear. In SMC, Supabase handles user registration and login, and I use RLS, or Row Level Security, to keep each user's data safe.

What I like most about programming is seeing the final creations, and what an internet connection, a computer, and the right tools can accomplish.

In the future, I want to apply this knowledge to the career I plan to study, to strengthen my skills. Thank you very much.

Uso JavaScript para que las cosas funcionen, React para crear las pantallas que la gente ve y toca, Node.js para el servidor que está detrás y Supabase para la base de datos donde se guarda la información.

Lo que más me gusta de la programación es ver las creaciones finales y lo que una conexión a internet, un computador y las herramientas adecuadas pueden realizar.
